# HTTP e Status Codes

Cliente <-> Servidor
Comunicação usando **HTTP**

Toda requisição possui:
- Método (ação)
- Status Code (resposta)

# Métodos HTTP
GET - Buscar
POST - Criar
PUT - Atualizar tudo
PATH - Atualizar parte
DELETE - Remover

# Status Code

2xx - Sucesso
3xx - Redirecionamento
4xx - Erro do Cliente
5xx - Erro do Servidor

# Principais Status
200 - ok
201 - criado
400 - requisição inválida
403 - proibido
404 - Não encontrado

# Erros do Servidor
500 - Erro interno
503 - Serviço indisponível
